# DormDeposit Trust
Safe housing deposits on Stellar for students without bank accounts.

## Problem & Solution
Students lose cash deposits to bad landlords. DormDeposit Trust holds deposits safely online and returns the money automatically when the stay ends.

## Stellar Features Used
- USDC Transfers
- Soroban Smart Contracts
- Trustlines

## Prerequisites
- Rust 1.74+
- Soroban CLI 20.0.0+

soroban contract build
